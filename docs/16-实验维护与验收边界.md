## 三项工作分别解决什么问题

| 工作 | 输入与输出 | 不能混用的结论 |
|---|---|---|
| B6 主训练恢复与大间隔微调 | 同阶段恢复需权重、优化器、缩放器和说话人映射；进入大间隔阶段则按配方选择初始化权重、重建该阶段优化器 | 主训练在继续，不代表大间隔阶段已经运行；CPU 准备器的完整检查不等执行许可 |
| 开源模型自动文字与时间标注 | 在原音旁保存独立 JSON 文件，绑定原件身份、模型和配置，保留未知、失败及原始和修补后的时间 | 标注文件发布成功，不代表转写正确或字界完整；机器看图和模型听辨不能记成人工审核 |
| 官方模型的完整字自然变长微调与评测 | 从官方骨干模型开始，使用完整的一个或几个字词，分别交叉注册端与测试端长度 | 固定秒数裁片压力测试、自动边界候选、主训练恢复和此实验不是同一条训练线 |

本轮正式自动标注范围是 VoxCeleb2、VoxBlink2、CN-Celeb2 的实际主训练或大间隔微调来源。两种用途重复引用的同一原件只计一次来源。MUSAN、房间脉冲响应、额外评测语料和历史业务诊断样本不加入这份主验收分母。原训练表抽中的受保护诊断来源仍须单独禁止进入后续训练，不能因原表未携带保护字段而失去保护。

## 自动标注怎样进入下一步

来源身份至少区分编码文件摘要、解码后原采样率多通道 PCM 摘要、模型实际单声道输入摘要和各自采样时钟。旧 FireRed 标注若只有路径、大小、时间与采样时钟绑定，就照实保存这种较弱身份，不能补写成旧原音 SHA 已核。

原始模型时间、库内修补时间和最终候选单位分别保存。新十进制原钟与legacy重建规则分版；撇号A/B仅作文字条件诊断，不提训练资格。运行中的旧标注包不热更新，当前仓库包导入修复也不能冒充旧A/B实测源码。零长、倒置、越界、超出支持语言、空转写、生成截断和未决读法必须完整计账；不能删除失败样本来改善分母，也不能裁切、均分粗词或把修补后的正长度当成完整字正确。

完整字消费工具默认只提出待核候选。工程格式导出也必须保留 `usable_for_training=false`、`usable_for_evaluation=false`、边界待审核状态、未核实说话人身份和独立的工程用途分组。正式训练和评测的默认输入检查仍应拒绝这些候选。显式请求导出而全部被拒绝，命令必须返回失败；默认只做完整计账时，成功退出只表示检查完成。

## 恢复与发布怎样验收

标注任务的恢复需用同合同、同原音、同源码的完整基线进行逐源比较。统计复用的旧结果与实际新执行的结果，核对旧文件字节和修改时间、缓存确实被消费、缺少阶段实际重新执行。若模型对批次组合敏感，就不能在恢复时改变未绑定的批次组合；单窗执行只消除这一项隐含影响，不保证模型答案正确。

发布记录必须绑定真实输出和对应输入，不能仅相信父进程退出码。对并发代次、锁、计算进程和资源归还的检查有现场条件，不属于合成 CPU 测试可以替代的部分。正式新任务若已经取得持久作业声明，后续失败应进入显式接续方案；不要删除声明或盲目重提来绕开去重。

## 历史证据与当前维护版本

历史两卡实测验证了当时冻结源码、模型、输入和环境的组合。把文件迁入本仓库、泛化路径、移除私有名单或重构依赖后，源码身份已经改变。应先跑仓库内合成回归，再按需要绑定原件做模型和 GPU 回归，分别记录结果。本页不宣布新仓库提交已完成 GPU 验证。

外部证据留在受控存储。公开仓库只存工具、合成测试、非敏感示例和证据格式说明，不保存真实业务音频、完整日志、原始标注名单或凭据。部署时另存 Git 提交、程序文件摘要、配置、模型与输入摘要；不能改历史冻结文件或其清单来隐藏差异。


## 受控接续还需哪些实际证明

model47受控接续保留原189来源，只允许新executor和故障取证helper形成独立190成员树，不重封原清单。先做完整模型/SGD/scaler与映射的实际CPU恢复，再做双卡有限更新/精确状态重构及注入非有限的完整取证。双卡的具体成功范围以已核报告为准，不能把同进程对象重构称为操作系统进程重启，也不能代替正式八rank准入。

正式worker在CUDA之前登记实际PID/PG/SID/start/nonce和独立GPU共享锁，父实核八份与新鲜空闲设备后才ACK。rank可能各有独立会话，父退出不能证明它们退出；已知组清理、未知持锁等待和重复信号处理都要保存证据。完整15001批和全rank一致后才允许每轮验证/保存。参见[固定接口](../tools/ptn_resume/INTERFACE.md)与[三段LM协议](../tools/ptn_resume/三段LM准备协议.md)。
