## 0. 读表前必须知道的公共前提

```bash
REPO=/root/code/github_repos/redimnet2-fork
PY=/root/miniforge3/envs/redimnet2/bin/python
cd $REPO   # 下文所有示例都以此为工作目录
```

| 事项 | 事实 |
|---|---|
| 训练解释器 | `launch.sh` 按 `REDIMNET2_PYTHON` → `REDIMNET2_ENV`（默认 `redimnet2`）→ 常见 conda 路径 → PATH 上 `python` 的顺序解析，并强制 `torch>=2.0` + 能 `import torchaudio` |
| 训练通信 | `torchrun --nnodes=1:1`，单机；`MASTER_PORT` 不设时自动绑 0 号端口取空闲端口；多机必须显式给端口 |
| 数据根 | 配方写死 `/root/group-shared/voiceprint/data/wespeaker_data`；训练表两种前缀（`/root/group-shared`、`/shared/group-shared`）混写，两者必须都能读 |
| 结果约定 | 每次训练写 `$EXP_DIR/{models/model_N.pt, train.log, val_log.csv, spk2id.json}`；续训=同一条命令重跑（按 mtime 取最新 `model_N.pt`，`start_epoch=N+1`） |
| 卡数 | 主训练默认 8 卡；`run_b6_mix_reproduction.sh` 硬要求**恰好** 8 张可见卡；`evaluate_b6_mix_reproduction.sh` 要求 ≥6 个 GPU id |
| 平台任务名 | 统一 `zhounan_` 前缀 + 优先级 6；本仓库所有工具**都不提交平台任务**，只准备文件与本地校验 |

| 标记 | 含义 |
|---|---|
| 🔴 | 会写生产数据 / 调外部 API / 触发平台计费或 GPU 长时间占用 |
| 🟠 | 会改系统目录（符号链接、挂载别名）、会写大量磁盘或整个 `$EXP_DIR` |
| 🟡 | 只读校验或只写自己的报告文件 |
| ⚪ | 纯 CPU 单测 / 合成夹具，无副作用 |

## 8. 已知坑（看起来能用，实际有雷）

1. **5 个 `.sh` 没有可执行位**（644）：`tools/open_annotation/launch_queue_handoff.sh`、`launch_portable_successor.sh`、`tools/ptn_resume/lm_launch/package_launch.sh`、`tools/ptn_resume/runtime/launch.sh`、`tools/ptn_reference/archive/launch.sh`。任何写成 `./xxx.sh` 的文档照抄必然 `Permission denied`，只能 `bash xxx.sh`（平台入口也要注意 Entrypoint 直接执行会失败）。
2. **两个 open_annotation 启动脚本依赖仓库里不存在的清单**：`launch_queue_handoff.sh` 需要 `queue-handoff-files.sha256`，`launch_portable_successor.sh` 需要 `controller-files.sha256`。它们只对"已冻结的控制树"成立；在仓库里跑第一行 `sha256sum --check --status` 就退出。二者还把解释器写死为 `/root/miniforge3/envs/qwen3-asr/bin/python3.10` 并校验其 SHA256。
3. **`tools/ptn_resume/build.py` 不能直接执行**：`from . import contracts` → `ImportError: attempted relative import with no known parent package`。必须 `python -B -m tools.ptn_resume.build`（INTERFACE.md 里也是这么写的）。
4. **`tools/ptn_resume/runtime/{entry,worker}.py` 在仓库内跑不起来**：`import ptn_contracts` —— 该名字只在冻结包里存在（`contracts.py` 被 builder 复制成 `runtime/ptn_contracts.py`）。`python runtime/entry.py --help` 直接 ModuleNotFoundError；`legacy_preflight.py` 同理。
5. **`wespeaker_lite/bin/train.py` 是 python-fire，不是 argparse**：`--help` 不会打印帮助，而是拿默认 `conf/config.yaml` 真的进入 `train()` 然后 `FileNotFoundError`；同时它硬读 `os.environ['RANK']` 与 `os.environ['WORLD_SIZE']`（`LOCAL_RANK` 缺省 0），**不在 torchrun 下必崩**。真实接口是 `--config <yaml>` + `--config_overrides` + 其余按 yaml 键透传。
6. **`train_b6_mix_cloud_8gpu.sh` 的 LM 缺省权重是"最新的"**：不传 `MODEL_CKPT` 时按 mtime 取 `model_*.pt`，在跑满 120 轮的目录里会拿到 `model_120.pt`；而本次受控口径要求第 115 轮。`tools/ptn_resume/lm_launch/run_lm.sh` 用"文件名必须是 `model_115.pt` + 字节 pin `65497b6a…aad5c`"挡住这件事——**直接调 cloud 脚本就没有这层保护**。
7. **`run_b6_mix_reproduction.sh` 不可移植**：`export DATA_ROOT=/root/group-shared/voiceprint/data/wespeaker_data` 是写死的，并显式拒绝 `NUM_EPOCHS/SAMPLE_NUM_PER_EPOCH/BATCH_SIZE/SAVE_EPOCH_INTERVAL/RECIPE/MODEL_CKPT/STAGE/EXP_DIR/PTN_EXP_DIR/REPRO/NUM_GPUS/RECIPE_DATA_PREFIX/VOX1_TEST_DIR/EXPECT_TRAIN_LINES` 共 14 个变量；`formal` 还需要 `SMOKE_SUCCESS_FILE` 里 8 个进程的 GradScaler 恢复证据 + PTN 64 步/LM 32 步逐点学习率一致证明。非该布局的机器只能用 `train_b6_mix_cloud_8gpu.sh`。
8. **`evaluate_b6_mix_reproduction.sh` 的前置比看起来多**：要 `$RUN_ROOT/lm/models/model_1.pt` + `lm/config.yaml`；要 ≥6 个 `CUDA_VISIBLE_DEVICES` id（少于 6 直接退出）；默认 `OFFICIAL_REFERENCE` 指向仓库内 `checkpoints/pretrained/b6-vb2+vox2+cnc2_v0-lm.pt`（不存在就退出）。
9. **`prepare_b6_cloud_paths.sh` 改的是系统目录**：在 `/` 下建 `/shared/group-shared`、`/root/group-shared` 两个符号链接（需要 root），拒绝覆盖非空目录；机器/容器重建后链接若不保留，需重跑本脚本恢复。
10. **`check_b6_mix_data.py` 把增强数据数量写死了**：MUSAN music 660 / noise 930 / speech 426、RIRS simulated_rirs 60000，多一个少一个都 `ValueError`；它写出的 `data_audit.json` 是 `run_b6_mix_reproduction.sh` 的强制输入（要求 `ok` 且 `lm_speakers_subset_of_ptn`）。
11. **评测脚本默认把 CSV 写进仓库**：`eval_vox1_checkpoints.py` 默认 `checkpoints/eval_vox1_results.csv`、`eval_ood_checkpoints.py` 默认 `checkpoints/eval_ood_results.csv`；`.gitignore` 只忽略 `checkpoints/pretrained/`、`checkpoints/eval_*_logs/`，所以默认值会污染 `git status`（会多出未跟踪文件）。评测时显式传 `--out-csv` 到仓库外更干净。
12. **`gpu_launch.py` 的 `--execute` 是 `action='store_true'` 且 `required=True`**：argparse 允许这种组合——必须出现该开关但不用带值。少写就是 `error: the following arguments are required: --execute`，容易误判成"没装参数"。
13. **`redimnet2` 环境的解释器二进制是别人的软链**：`/root/miniforge3/envs/redimnet2/bin/python3.11 -> /root/miniforge3/envs/audio-flamingo/bin/python3.11`，标准库因此从 `audio-flamingo` 读取（`--help` 的 traceback 路径可见），site-packages 仍取 `redimnet2`（`sys.prefix` 正确、torch 2.4.0+cu124）。删除或升级 `audio-flamingo` 会连带影响 `redimnet2`；是否为刻意共享未验证。
14. **`applications/speaker_rec/launch.sh` 找不到环境时只 warning**：`REDIMNET2_ENV` 指的环境不存在就退回 PATH 上的 `python`，只在 stderr 打一行 WARNING；卡数默认 8，卡少于此值直接启动失败。
