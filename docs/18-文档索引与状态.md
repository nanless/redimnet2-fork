## 1. 易变事实只放在一处

审计已经发现，正文里写死的状态性断言会自己变成假话。从这一版起这样处理：

| 类别 | 允许写在哪 | 例子 |
|---|---|---|
| 易变事实 | 只写在 [STATUS.md](STATUS.md)（自动生成，不手改） | HEAD、未提交改动数、脚本权限位、pytest 摘要、产物 sha 与大小、"最近三次提交跑了什么" |
| 稳定事实 | 正文直接写 | 代码结构、参数名、判据逻辑、"这条门要求什么" |
| 带日期的历史观测 | 正文写，标日期并给复核命令 | "2026-11-01 13:14 的 v3 崩溃形态" |
| 目录里有什么 | 正文写命令，不写结论 | `ls docs/*.md \| wc -l`、`ls tools/open_annotation/tests/test_*.py \| wc -l` |

三条操作规则：

1. **要写数字，先写命令。** 能给出“读者自己跑一下就能得到”的命令的，正文不抄结果。
2. 确实要写具体数字时（例如官方 EER 表、已发布产物的 sha），写成“截至 <日期> 的观测”，紧跟一行复核命令。
3. “已修好/已验证/工作树干净/排队中”这类话不写进正文：它们都会过期。改成“看这条命令的输出”或“见 STATUS 第 N 节”。

### 工具：状态统一由生成器产出

```bash
cd /root/code/github_repos/redimnet2-fork

python3 tools/gen_status.py          # 重新生成 docs/STATUS.md（会真跑一次 pytest）
python3 tools/gen_status.py --fast   # 同上，跳过 pytest（只想刷新其余各节时用）
python3 tools/gen_status.py --check  # 校验 STATUS.md 是否已过期；过期退出码 1
python3 tools/gen_status.py --lint   # 扫描 docs/ 与技能里的易变硬编码断言；命中退出码 1
```

* 纯标准库、不联网、不写仓库外路径；输出不含生成时间戳，所以**可以 diff**。
* `--check` 不重跑 pytest（复用 STATUS.md 里已存的测试节），因此适合放进提交前检查。
* `--lint` 的规则包括：写死 HEAD、写"工作树干净"、写死权限位（644/755）、写死退出码、写死测试计数、写"已修好"、写"排队中"、写目录清点，以及**用 `文件:行号` 指向别处**（第二个数字 ≥60 的才判，避免把 `13:14` 这种时刻误伤）。
* 确实要写时，在同行加 `<!-- volatile-ok: 原因 -->` 就地豁免，并在 PR 里说明理由。

改完文档、提交之前至少跑一次 `--lint`；改动了会影响状态的东西（代码、产物、权限位）时，再跑一次不带参数的生成加 `--check`。

### 3.1 `docs/15` 的「LM 1 轮、13,075 步」与配置一致

一致：`REVIEWABLE_CONTROL` 就是 4 个 CPU 辅助脚本；引擎源是无条件等式；pilot 规模门是 `n>=3000 and rc==512`。**上一版列为"未核"的 `engine_source_files` 计数已经核过：16 项**（从 `admission-20261108/contracts/*silver*.json` 读 `len(engine_source_files)`）。复核：

### 3.3 `docs/10` 第 14.9 节的提交通道：结论仍成立，措辞要按实测改

* CLI 在，但**读不到任务**：`~/.volc/credentials` 不存在，只有 CLI 不认的 `access_token`。
* 报错是 `AccessKeyId or SecretAccessKey is empty, please check $HOME/.volc/credentials or config it by using volc configure`，随后 CLI 自己打一行 `volc ml_task: exit status 255`；**但 shell 的 `$?` 实测不是 255**（本次 `get` 得到 1，`list` 经管道后得到 0）。前面还会有版本升级提示和 metrics 警告。
* 结论不变：**"命令行报错"≠"任务没跑"**。平台终态只能看控制台详情页。
* 复核：`export PATH=/root/.volc/bin:$PATH; volc ml_task get -i <task-id>; echo rc=$?`（把整段输出连 `rc` 一起记下来，不只记一个数字）。

## 5. 交叉链接

`docs/*.md` 的相对链接做过全量检查，结果为 0 条死链。这个检查只证明链接能落到文件，不证明被链内容正确。它属于可复跑项，数字不抄进正文：

```bash
python3 - <<'PY'
import re, os, glob
bad = []
for f in sorted(glob.glob("docs/*.md")):
    for link in re.findall(r"\]\(([^)]+)\)", open(f, encoding="utf-8").read()):
        if link.startswith(("http", "#", "mailto")):
            continue
        p = os.path.normpath(os.path.join(os.path.dirname(f), link.split("#")[0]))
        if p and not os.path.exists(p):
            bad.append((f, link))
print(len(bad), bad)
PY
```

* 两处都提到同一件事时，**以本文为准**；README 只保留会影响动手的条目。
