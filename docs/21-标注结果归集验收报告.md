## 2. 校验方式

1. **收据计数**：每代 `run/queue/completed/*.json` 的文件数与迁移前相等（4,624 / 1,824 / 17,750 / 3,863）。
2. **目录计数**：三个数据集的说话人目录数与源端相等。
3. **文件抽样**：每代每数据集抽一个说话人目录，比较文件数与单文件字节数。
4. **identity.json 存在性**：每代 profile 内都在。
5. **源删除**：四代的 `labels` 与 `queue` 在迁完后删除；`20261109` 的整棵树已删净，其余三代的空壳目录在收尾删除。

```bash
  --index /root/group-shared/voiceprint/open_annotation/_index/done-index.jsonl \

```
