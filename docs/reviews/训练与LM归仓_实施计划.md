# 训练与大间隔微调维护代码归仓计划

本次只维护本仓库的新代码，不改服务器、现训或旧冻结材料。先核源字节，整理大间隔微调的跨段CPU准备器、完整字训练、按时长训练及其启动和评测入口。真实业务音频、标注原件、私有样本清单、模型和日志不入库。

## 目录与来源

- `tools/lm_continuation/`：已通过独立审阅的跨段准备v4与它固定复用的四个必要检查模块；测试改用合成文件，不引用本机历史目录。
- `duration_ft/`：v3完整源快照中的数据/训练代码，加本机当前完整备份中的评测、恢复合同和统计模块；同名先比较。
- `word_ft/`：优先本轮新取的schema、prepare、evaluate、gpu_train原字节；补齐当前备份中的align、train、gpu_resources及包定义。
- `word_ft_v3/`：v3完整源快照，当前新取的train同字节；保正式完整字与工程候选的资格分层。
- 对应 `scripts/`、非私有配置示例及 `tests/`：只复制维护入口和合成测试，不复制历史运行证据或现场数据清单。
