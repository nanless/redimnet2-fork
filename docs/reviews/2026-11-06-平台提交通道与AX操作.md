# 平台提交通道与 AX 操作手册：CLI 的边界与控制台复制的可用路径

本记录把 11-06 在平台提交 LM 任务时踩到的通道限制与可复用的操作方式固化下来，供后来人直接照做。时间均为北京时间。**本文只描述通道与操作，不评价任务结果**；LM 任务本身见[提交记录](2026-11-06-LM从PTN115提交.md)。

## 一、CLI 存在但当前不可用

服务器有官方 CLI：`/root/.volc/bin/volc`（v1.2.55）与同目录的 `mlp`。**它不在 PATH 里**，直接调用 `volc ml_task` 会报 `exec: "mlp": executable file not found in $PATH`；正确用法先补 PATH：

```bash
export PATH=/root/.volc/bin:$PATH
```

补完 PATH 后仍**不可用**，实测报错：

| 命令 | 实测报错 |
|---|---|
| `volc ml_task get -i <task_id>` | `AccessKeyId or SecretAccessKey is empty` |
| `mlp job list` | `AccessKeyId or SecretAccessKey is empty` |

原因：`~/.volc/credentials` 不存在，只有 `access_token`，而 CLI 不认 token 形式的凭据。**结论：CLI 通道当前需要 AK/SK，未配置。**

另有一条容易踩的语义：`ml_task list` 的自述是"列表打印**所有非终态**的任务"。任务一旦结束（成功/失败/停止）就不在 `list` 里，**查历史只能用 `get -i <id>`**。用 `list` 找不到旧任务不等于任务不存在。

## 二、可用通道：控制台 + 复制任务

已验证可用的路径是浏览器控制台的"复制任务"，能把旧任务的镜像、队列、规格、挂载、优先级等整份带出来，只改需要改的三处。

| 步 | 动作 | 要点 |
|---|---|---|
| 1 | 任务列表页 → 目标行操作列点 **`复制`** | 打开预填表单，URL 形如 `/customTask/create?Id=<task>` |
| 2 | 用 **AX 元素动作** 改三处 | `AXPress` 点按钮；`set_value` 填 `任务名称` / `描述` / `入口命令`（`AXTextField` / `AXTextArea`） |
| 3 | 点 **`复制任务`** 提交 | 提交后回列表页核状态与实例 |

一次 LM 提交实际只改了这三处，其余字段（镜像 `prod-cn-beijing.cr.volces.com/aiplatform/dev_zhounan:4.0`、队列 `aiplatform-SPEECH`、规格 `ml.pni2l.28xlarge`、优先级 6、自动重试关闭、两处挂载）全部沿用旧任务。

## 三、为什么必须用 AX 元素动作，而不是坐标点击

| 现象 | 机制 | 处置 |
|---|---|---|
| 坐标点击落到相邻行 | 页面顶部"所有产品服务"大菜单展开时**整体遮挡**，屏幕坐标系与可见元素错位 | 先 `Escape`/关闭菜单，或先在 AX 树里确认目标元素 |
| AX 索引点了没反应/点错 | **AX 快照 60 秒过期**，重采后索引移位 | 一次采样后立刻动作；过期就重采再动作 |
| 内层子元素不稳定 | 容器类节点（`AXGroup`/`AXUnknown`）随渲染变化 | 直接找可交互的叶子（`AXButton`/`AXTextField`/`AXTextArea`） |

## 四、`AXIncrementor`：数字输入框填不进去

"最长运行时间"这类**数字输入框（`AXIncrementor`）不吃 `set_value`，也不吃合成键入**——写进去会被清成 0。实测可用的做法是**留空**：平台接受空值，任务照常提交（本次 LM 提交该字段即为空）。不要为了"填满表单"去反复尝试，越试越容易改坏其它字段。

## 五、能读到什么（提交后核验用）

平台详情页可直接读到：镜像、队列、优先级、规格型号、挂载、框架、时限、重试策略、实例信息与实例终态。这些是**平台侧记录**，与包内自证（`sha256sum`、`LM_GATE_VERIFIED`）互为独立证据，不能互相替代：平台显示"运行中"不证明首屏门通过，首屏通过也不证明实例没被回收。

## 六、不能宣称的

- "CLI 不可用"是当前凭据配置的结论，不是平台能力结论；配好 AK/SK 后需重新实测。
- 用 `list` 查不到任务**不代表**任务从未存在。
- 控制台能读到配置**不等于**任务按该配置跑起来；实例终态与首屏日志要分别核。
- 本文不含任何 AX 库的内部实现结论，只记录"哪种动作实测可用"。
