1. 清点全部 Markdown、README、项目技能和文档中的相对链接，区分仓库内文件、仓库外原始证据和网络链接。文件是否存在只证明入口可到达，不证明正文或网络服务正确。
2. 核对中文导读、AGENTS、历史训练记录的日期和语义。特别区分语音活动检测边界与完整字边界、主训练恢复与跨阶段大间隔微调、自动候选标注与可训练的人工审核单位。
3. 建立 `.agents/skills/redimnet2-reproduction-ops/` 作为项目技能维护源。只收可公开流程和本仓库代码路径，不复制业务音频、真实样本名单、完整日志、平台凭据或机器专属配置。安装目录由维护者从此同步，不能成为唯一源码。
4. 交叉阅读 `tools/lm_continuation/`、完整字训练与评测模块、`tools/open_annotation/`。采用合成输入检查异常拒绝、路径作用域、资格字段、恢复和发布协议；发现确定问题交负责实现者修改，再复验。
5. 集成完成后再次核相对链接、代码入口和新增文件；记录实际命令、退出码、审阅范围与未验证项。统一提交由主维护者执行，作者与提交者均为 nanless，提交说明用详细中文。
