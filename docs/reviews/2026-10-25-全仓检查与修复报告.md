## 2. 发现、修复与复验

| 问题 | 触发或影响 | 修复与验证 |
|---|---|---|
| 旧采样器跨轮拼接使同一全局批重复来源 | 原有限来源池在轮边界可重复抽到同一索引 | 用最小公倍数平衡的确定性批次安排，检查批内唯一、来源覆盖和乱序重放；独立检查230组组合×60批 |
| 布尔值、非有限数值及错误整数被接受 | 步号、种子、长度、学习率或模型状态可能产生不可复现/无效训练 | 增加明确类型和有限性检查；修复后的代码身份进入保存与恢复检查，旧身份不静默沿用 |
| 官方初始化摘要或统计源码身份未完整绑定 | 相同配置名可能对应不同权重或不同统计代码 | 补明确权重摘要及维护源码身份，保存反例；不重写历史冻结文件 |
| 仓库测试依赖Mac实验目录或真实标注原件 | 新机器无法复验，也不宜把真实业务数据公开 | 改为合成夹具和仓库相对入口；真实原件作为外部受控输入，缺失时如实拒绝 |
| 标注的新任务总根包含冻结代码时被误拒 | 参数化后的两处路径规则互相矛盾，合法新布局在GPU前被挡 | 任务总根与具体输出分别检查；继续拒绝输出与代码重叠、软链逃逸及不安全锁范围 |
| 正式输出等于双卡证据目录、锁等于任务根漏拒 | 两种用途可能混写或锁范围不正确 | 补等号及双向祖先关系反例；独立验证不发生外部写入 |
| 模型真实长度被静默截断/夹紧 | 0、负数、2.7、True或超长数能生成看似合法掩码 | 校验非空一维、有限整数、范围及批大小；混合NumPy/Torch布尔值拒绝，合法uint64保持兼容，溢出拒绝 |
| 显式连续衰减模式未到声明末步学习率 | `decay_to_final_lr=true`、非阶梯模式最后一步高于目标 | 最后实际优化步使用声明目标；分别测两种缩放方式，历史默认衰减公式不变 |
| 启动环境保护依赖Bash4.2专有语法 | 本机Bash3.2无法解析，检查入口不可携带 | 改为兼容间接“是否定义”检查；所有禁用参数的空值和非空值都继续拒绝 |
| 测试汇总把普通stdout当成结果 | 普通`skipped=0`或假“Ran 999”可掩盖真实摘要；零用例可能误判通过 | 只解析stderr标准完整摘要，必要测试必须有非零用例和完整状态；8个独立反例全部通过 |
| 文档把VAD边界写成完整字保证 | 实际VAD会漏首尾、内部仍可能切字，且有回退路径 | 保留历史数据，明确各分母、标注边界检查与人工字界的区别 |
| 声纹阈值升降的虚警/漏检关系写反 | 学生按原文理解会反向调整阈值 | 写清相似度大于等于阈值接受：提高阈值增加漏检，降低阈值增加虚警；历史192格数字逐CSV重核 |
| 文档扫描误纳隔离环境和私密原始输出 | 全树遍历可能扫描`.venv`和`.audit-local` | 受控仓库遵循Git忽略规则，合成无Git目录剪枝；实际反例证明被忽略的非法UTF-8文件不会被读取 |
| PTN参考原文件含两条固定诊断标识 | 不符合公开仓库不纳真实诊断名单的范围 | 该文件改用已审公开派生版；历史摘要与公开摘要并列，另外9文件保持原字节；不再声称10份都为历史原字节 |

实现和独立审阅发现的问题均保留修前证据，修复后再跑原反例。参考源码的历史身份与派生身份分开；不会通过更新原冻结摘要来隐藏差异。根目录Git忽略规则同时排除本地审查输出、隔离环境、音频、模型及张量原件，但忽略规则不能代替对已跟踪文件的提交审查。
