# 完整字自然变长的双卡与八卡受控入口

本目录保持一个平台父进程、单机双卡或八卡的明确结构。`topology.py`拒绝多机和隐式平台逐rank启动；每个优化步选择不同来源的完整字族，1/2/3/6字记录必须来自同一原声、同一说话人和同一起点，结束点严格递增，不能任意拆一个粗词成假字。

`train.py`逐条真实长度前向并按条数累积损失，保冻结批归一化统计及仿射梯度。原声时钟、源身份、完整优化步、随机状态和样本位置均进入恢复合同；GPU保存点不能拿CPU保存点替代，世界大小、配置或源码改变也拒绝。[共享数值守卫](../duration_ft/config_checks.py)已纳入源码/资源票据身份，新维护版不继承旧GPU验收。

`resources.py`核设备UUID、全部compute PID、两次独立空闲快照、协作锁、父子进程身份与固定显存预算。0%利用率或未知PID都不等于空闲。不杀别人的进程、不共享空余显存。`scripts/launch_word_v3.py`区分只探测和显式执行，超时只清理本次身份已证的进程。

代码示例的四步配置只是工程设置。八卡且每卡两个来源时，至少需要16个真实不同来源字族；不能复制四个family改名凑数。真实GPU测试应先完成双卡前反向、梯度/批归一化、完整步保存、连续与断点恢复和资源归还，再审八卡。CPU模拟不替代这些证据。
