# 01 背景与评测说明

## 我们在验证什么

官方 README 公布了一批预训练模型在标准测试集上的等错误率（EER）。本工作做的是：

1. 下载同一批权重；
2. 用同一类协议（余弦相似度 + EER）自己再算一遍；
3. 看数字是否对得上。

若对得上，说明：**权重可用、数据协议理解正确、评测代码可信**，后续在此基础上改模型或换数据时，才有稳定基线。

## EER 用白话说

说话人验证会给「是否同一人」打一个分数。阈值高了，容易把陌生人误认成真身（虚警）；阈值低了，又容易把本人拒之门外（漏检）。

**等错误率（EER，Equal Error Rate）**：调节阈值，使「虚警率 = 漏检率」时的那个错误率。常用百分数表示，例如 `0.42` 表示 0.42%。

本仓库评测脚本用的是：

- 对语音提 **L2 归一化后的说话人向量**（embedding）；
- 试验对（trial）做 **余弦相似度**；
- 用 ROC 曲线求 EER（与常见 WeSpeaker / Kaldi 复现习惯一致）。

## 官方表里有两类数字

1. **VoxCeleb1 主表（O / E / H）**  
   几乎所有官方型号都会报。难度大致：O（相对干净）→ E（更多试验对）→ H（更难）。

2. **混合数据训练型号、训练集之外的试验（B / VOICES / CN-Celeb / SITW）**
   指音频或说话人分布与纯 VoxCeleb2 训练场景不完全一样的试验集合。只对若干「混合数据训练」的型号报，用来看模型换场景后是否掉点。详见 [03-域外试验结果.md](03-域外试验结果.md)。

本次 **不做 SITW**（需向数据方申请），其余均已评完。

## 如何阅读「实测减去官方」

\[
\Delta = \text{实测 EER} - \text{官方 EER}
\]

也就是：**我们算出的等错误率，减去官方表上的等错误率**。表里常简写成 Δ。

| \|Δ\| 大致范围 | 怎么理解 |
|----------------|----------|
| ≤ 0.02 | 非常接近，数字与官方表一致 |
| 0.02～0.10 | 仍可接受；可能来自实现细节或浮点差异 |
| ≫ 0.10 | 优先怀疑协议或数据是否用错（我们在 CN-Celeb 上踩过这个坑） |

**注意：** 略小于 0 并不等于「我们比官方更强」，也可能是试验对过滤、随机性或实现细节不同；重点是数量级是否一致。

## 评测环境（摘要）

- 模型包装：`ReDimNet2Wrap`（与官方推理一致）
- 脚本：`scripts/eval_vox1_checkpoints.py`、`scripts/eval_ood_checkpoints.py`
- 环境：conda `redimnet2`（PyTorch 2.4 + CUDA）
- 打分：**整段语音**一条说话人向量（未做多裁剪融合，除非协议另有说明）

> **这里的「整段」和训练日志不是同一个口径，不能混着比。**
> 本目录所有数字都按整段音频算；而训练时写进 `val_log.csv` 的那一列
> （列名 `vox1-eer-8s`，**旧名 `vox1-eer-fl`**）只读每段音频开头 8 秒，不足 8 秒的部分还会用开头循环补齐
> —— 旧名里的 `fl` 写作 full length，但它从来就**不是全长**，所以才改了名。
> 同一个权重 `b0-vox2-lm` 上，整段评测得 1.042%，8 秒窗口得 1.074%，差 0.032 个百分点。
> 要核对「实测减去官方」，请用本目录的数，不要用训练日志的数。

更细的路径与命令见 [04-数据与复现步骤.md](04-数据与复现步骤.md)。

## CN-Celeb 的一个重要细节

CN-Celeb 有两种常见注册方式：

| 名称 | 做法 | 与官方 README |
|------|------|----------------|
| **Avg（多段平均）** | `enroll.map` 列出多段注册语音，各自提说话人向量再平均 | **应采用这种协议**（官方 CN 列对应的是 Avg） |
| Concat（拼接） | 使用拼好的 `*-enroll.wav` 整段提特征 | 数字会系统性偏高 |

我们第一次误用了「单段拼接注册」列表，CN-Celeb 偏差一度达到约 0.9；改为 Avg 后降到约 0.09。  
**复现训练集之外的试验数字时，协议比「脚本能跑通」更重要。**
