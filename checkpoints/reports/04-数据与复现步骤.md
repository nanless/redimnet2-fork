## 评测命令示例

以下均在仓库根目录执行。把数据路径换成你的机器上的位置即可。

### Vox1-O / E / H

```bash
python scripts/eval_vox1_checkpoints.py \
  --ckpt-dir checkpoints/pretrained \
  --vox1-root /root/group-shared/voiceprint/data/speech/speaker_verification/voxceleb1 \
  --protocols O,E,H \
  --device cuda \
  --out-csv checkpoints/eval_vox1_rerun.csv
```

注意这里用的是 **`--protocols`**（取值为 `O`、`E`、`H` 的逗号列表，默认只跑 `O`），
不是 `--benchmarks` —— 后者是下面那个域外脚本的参数，两个脚本的参数名不一样，别弄混。
另外 `--vox1-root` 指到 VoxCeleb1 根目录即可，脚本自己会在该目录或其 `protocols/` 子目录下找协议文件。

（其余参数以脚本 `--help` 为准；历史结果已写入 `eval_vox1_*_all.csv`。）

### 训练集之外的试验：仅混合数据训练的型号，CN-Celeb 用 Avg

```bash
python scripts/eval_ood_checkpoints.py \
  --only-mix \
  --benchmarks Vox1-B,VOICES,CN-Celeb \
  --cnceleb-mode avg \
  --vox1-root /root/group-shared/voiceprint/data/speech/speaker_verification/voxceleb1 \
  --voices-root /root/group-shared/voiceprint/data/speech/speaker_verification/voices \
  --cnceleb-root /root/group-shared/voiceprint/data/speech/speaker_verification/cnceleb \
  --device cuda \
  --out-csv checkpoints/eval_ood_rerun.csv
```

`--cnceleb-mode concat` 会改用拼接注册语音，**数字不会与官方 README 主 CN 列一致**，一般不要用。

## 权重文件命名

```text
b{0-6}-vox2-{lm|ptn}.pt
b6-vb2+vox2_v0-{lm|ptn}.pt
b{3,6}-vb2+vox2+cnc2_v0-{lm|ptn}.pt
```

- `b0`…`b6`：模型规模档位  
- `vox2` / `vb2` / `cnc2`：训练数据配方  
- `lm`：大间隔微调后；`ptn`：主训练阶段（微调前）  

共 **20** 个文件，目录：`checkpoints/pretrained/`。

## 常见坑

1. **Vox1-B 用错协议副本**  
   请用 `protocols/list_test_bilingual.txt`（约 80.8 万行），不要用更短的那份。

2. **CN-Celeb 协议名含 Avg，实际却是拼接路径**  
   必须以 `enroll.map` 多段平均为准（见 01、03 两节）。

3. **只对了一个训练集之外的试验集合就宣称全面复现**  
   建议至少 Vox1-O + 一个训练集之外的试验集合（如 VOICES 或 CN-Celeb）。

4. **SITW**  
   无数据时不要填空表或编造数字；直接注明「未评」。
