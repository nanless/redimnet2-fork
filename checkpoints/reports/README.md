# 官方预训练模型复现评测报告

面向刚接触说话人验证的研究生。这里汇总本仓库对 **ReDimNet2 官方预训练权重** 的复现结果：我们测到的等错误率（EER），以及与论文 / README 表格的差异。

## 先看这里

在约定范围内（不含 SITW），**复现结果与官方数字一致**。绝大多数协议上，实测减去官方的差值在 **0.01～0.06** 个 EER 百分点以内；CN-Celeb 在改用正确的「多段注册取平均」协议后，最大偏差约 **0.09**。

> **这些数字来自读整段音频的评测脚本，和训练日志 `val_log.csv` 里的那一列不是一回事。**
> 本目录的每一个数都由 `scripts/eval_vox1_checkpoints.py`、`scripts/eval_ood_checkpoints.py` 产出，
> 它们**把每段音频整段读进来**再提说话人向量；
> 而训练过程中写进 `val_log.csv` 的 `vox1-eer-8s`（**旧名 `vox1-eer-fl`**）只读**每段音频开头 8 秒**，不足 8 秒还会循环补齐。
> 旧名里的 `fl` 写作 full length，但它并不是全长口径，所以才改成现在这个名字；数值口径没有变。
> 同一个权重 `b0-vox2-lm` 上两者差 **0.032 个百分点**（整段 1.042% 对 8 秒窗口 1.074%）。
> **所以不要拿训练日志的数字来核对本目录的表**；本目录的数字才能和官方表对照。

## 评测脚本在哪

两个评测脚本在仓库根目录的 `scripts/` 下（不在 `applications/` 里）：

| 脚本 | 测什么 |
|------|--------|
| `scripts/eval_vox1_checkpoints.py` | VoxCeleb1 的 O / E / H 三个协议 |
| `scripts/eval_ood_checkpoints.py` | 域外试验：Vox1-B、VOICES、CN-Celeb |

两个脚本都内置了官方的目标数字，跑完会直接算出"实测减去官方"的差值。
用法与命令示例见 [04-数据与复现步骤.md](04-数据与复现步骤.md)。

## 原始数字文件

合并后的 CSV 仍放在 `checkpoints/` 根目录，便于脚本读取：

- `eval_vox1_O_all.csv` — Vox1-O
- `eval_vox1_EH_all.csv` — Vox1-E / H
- `eval_ood_all.csv` — Vox1-B、VOICES、CN-Celeb（Avg）
- `eval_cnc_avg_all.csv` — CN-Celeb Avg 单独汇总

## 术语速查

- **EER（%）**：等错误率，越低越好。本报告单位一律为百分点。
- **Δ（实测减去官方）**：`实测 EER − 官方 EER`。接近 0 表示数字与官方表一致；略负表示我们测得稍低一点（不一定等于「更强」）。
- **lm / ptn**：大间隔微调后的权重 / 主训练阶段权重。
- **混合数据训练的型号**：在 VoxCeleb2 之外混了 VoxBlink2、CN-Celeb2 等数据训练的型号（文件名含 `vb2`、`cnc2`）。
