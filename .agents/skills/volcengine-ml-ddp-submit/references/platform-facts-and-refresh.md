# 平台事实的时效与复测方法

平台侧的值（镜像 tag、规格型号、队列、优先级、源任务、CLI 版本）都会变。文档写错它们，比不写更糟：读到的人会照着填，然后卡在提交前或者提交出错误配置。这份文件不重复表格，只说明**哪些值多久会变、变的时候到哪里重核、各条事实由哪份文档维护**。

实测基准 2026-11-09。

---

## 1. 主机与网络

| 事实 | 值 | 复测方法 |
|---|---|---|
| 开发机主机名 | `di-20260825114741-2bbpx` | `ssh dev_a800_2gpus hostname` |
| 同组另一台 | `dev_a800_4gpus` 对应 `10.43.6.242:2222`，2026-11-09 仍连接超时 | `ssh -o ConnectTimeout=10 dev_a800_4gpus hostname` |
| 内网可达性 | `ping 10.43.6.199` 2026-11-09 实测 3/3 通，平均 25.4 ms | `ping -c 3 10.43.6.199` |
| 内网不通而公网正常 | 判为 VPN 掉线，不是平台故障 | 同上 + `curl -m 8 https://www.baidu.com` |

`dev_a800_4gpus` 的超时从 2026-10-14 记到 2026-11-09 都没变。一次超时推不出机器已下线、也推不出两台机器共用磁盘；用户指定主机时先核 hostname、挂载与 realpath。

## 2. 会变的值和重核节奏

| 值 | 变化速度 | 提交前是否必须重核 | 重核位置 |
|---|---|---|---|
| 任务终态、排队位次 | 分钟级 | 是 | 控制台任务列表/详情 |
| 队列容量、AZ 是否可选 | 天级 | 是 | 提交表单的队列下拉 |
| 镜像 tag 是否存在 | 周级 | 是 | Image Center |
| 规格型号名（如 `ml.pni2l.28xlarge`） | 月级，目录调整即失效 | 是 | 表单规格选择器；历史名不可用 |
| CLI 版本与凭据 | 周级 | 提交前顺手看一眼 | `volc` 启动横幅、`ls /root/.volc/` |
| 控制台会话有效期 | 会话级 | 否，遇到再处理 | 实际操作中过期即知 |

判断标准很简单：**能在表单里选到的值，以表单为准；只能从历史文档读到的值，提交前必须重核。** 历史文档里出现过 `ml.hpcpni2l.28xlarge`，当前实际任务详情写的是 `ml.pni2l.28xlarge`，这就是“照抄历史名”会踩的坑。

## 3. 各条事实由哪份文档维护

同一件事只在一处维护，其他文档链接过去。改值时只改主文档。

| 事实类别 | 主文档 |
|---|---|
| 控制台复制流程、入口写法、AX 操作、会话与网络中断处置、首屏自检 | [控制台复制任务提交](console-clone-submission.md) |
| 复制来源任务及其字段基线（镜像、队列、规格、优先级、时限、重试、挂载） | [控制台复制任务提交](console-clone-submission.md) 第 2 节 |
| 表单字段规则、挂载方案、提交前检查清单、提交后核验 | [平台 DDP 任务工作流](platform-ddp-workflow.md) |
| 排队、失败三步定位、交接时间窗 | [排队、失败定位与交接窗口](queue-and-failure-triage.md) |
| CLI 通道现状与凭据 | [控制台复制任务提交](console-clone-submission.md) 第 1 节 |
| 实验合同（batch、拓扑、数据、输出） | 各项目技能，不在本技能 |
| 仓库侧的易变事实（HEAD、产物 sha、测试计数、最近提交任务表） | 仓库 `docs/STATUS.md`，自动生成，不手改 |

`docs/STATUS.md` 的用法：它声明自己只承载易变事实，正文不复制其中的数字。引用时写“见 STATUS.md 第 N 节”，不把数字抄进别的文档——抄过去就会过期，而自动生成的那份不会。

## 4. 写文档时的取舍

- 能实测的就写实测值并标日期；不能实测的写“用户观测”或“未验证”，并写清缺什么才能验证。
- 同一事实第二次出现时改成链接，不复制。复制两处，改的时候只会改一处。
- 带日期的文件名（如 `console-clone-submission-20261106.md`）说明它是某天的快照；一旦成为长期维护的主文档，去掉日期，把日期写进正文首段。
- 平台侧观察到但无法复现的现象，写现象和当时的判断，不写机制结论。例如“点 `6` 后仍显示 `4`”是现象，机制未查明。
