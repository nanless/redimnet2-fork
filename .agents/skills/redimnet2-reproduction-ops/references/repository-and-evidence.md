# 仓库、部署和证据

代码、脚本、可公开配置、测试与文档的持续维护源都在本仓库。技能源也在 `.agents/skills/`；安装副本只做同步，修改后记录源提交和逐文件摘要。

外部运行证据至少说明观测日期、程序摘要、模型与输入摘要、用途和实际输出。公开仓库可保存证据字段说明和合成夹具，不保存业务原件、完整日志、诊断名单、密钥或访问令牌。即使旧文件就在本机，也不因此获得公开发布授权。

新仓库版本有任何依赖路径、异常规则、身份读取或输出作用域变化，就按新源码验证。历史冻结清单保留原文；不能重算旧清单来宣称新旧相同。部署副本与仓库提交需能追溯，不能以仓库外实验目录为唯一现行实现。

文档检查相对链接和代码入口，并区分“规划”“合成 CPU 通过”“真实模型通过”“GPU 恢复通过”“人工边界审核”。平台表单提交成功只证明提交结果；还需回读唯一任务、挂载、rank、日志与检查点。结果未知时先查重，不自动再次提交。

仓库静态入口是 `scripts/check_repository.py`，CPU 分组入口是 `scripts/run_cpu_checks.py`；先看 `--help`，结果写到本次不存在的 `.audit-local` 新文件或目录。静态检查不跟随受控软链、不覆盖已有文件，拒绝非有限 JSON 与重复键；CPU 汇总有跳过、预期失败、零用例、超时或失败时不能记成完整通过。用例数量随版本变化，以本次实际记录为准，不拿历史报告数字当验收目标。

持久作业声明属于去重协议。新任务若在取得声明后失败，应准备显式恢复入口和新鲜资源证明，不能删除声明或锁文件来强行重跑。不要按文档维护请求自行启动、停止或迁移现训。

用户明确要求控制台工作期间保持屏幕不锁定时，可使用本轮拥有的临时电源保活，实读`pmset -g assertions`确认。`caffeinate -u`未给时间时的用户活动断言默认很短，不能仅凭进程还在就声称持续防空闲锁屏；同时核防熄屏、休眠和用户活动的实际期限。不改永久锁屏或登录安全设置。将PID、启动时间和完整命令记在本仓库被忽略的本地证据目录；继续工作前先读已有记录，结束时只撤销身份仍匹配的本轮进程，不按名称杀掉其他保活。保活不是后台巡检或训练启动授权。


## 本轮构建和复验中已证实的失效方式

新恢复包配置必须使用真实YAML并做逐类型回读断言，不能只验证JSON语法。模块既有脚本又有包消费者时，使用显式`if __package__`选择相对或脚本导入；不要用宽泛`except ImportError`掩盖依赖内部错误。独立临时cwd、清除PYTHONPATH后实际导入，才能发现测试进程已插入源码目录所掩盖的路径问题。

打包的每个必需文件都必须存在，缺失立即失败，不能写`if exists`静默漏包。保留仓库相对目录，例如工程器在`tools/ptn_resume/`，资源模块是仓库根`word_ft_v3/`；部署目录错了不能先改正确源码去迎合错误包。归档逐成员核regular/safe相对路径/字节/SHA，再在脱离仓库的cwd验证实际导入。旧失败包、父日志和未初始化CUDA的事实均保留。

本轮619项完整运行曾真实失败于完整字组的包导入；已修后的局部通过不替代新的全量汇总。较早549项通过、后来的619失败、修后624项无跳过通过分别记录；退出信号、二进制和NFKC配组反例完成后的上次633项也曾实际0跳过通过；以后仍有新增审计时，最终数量只从实际总结读取，不能因预期有多少用例就提前宣布全部通过。真实CPU恢复、双卡finite/injected和正式八卡为不同源码及资源验收；同一source190也不使不同父入口自动继承运行成功。

本次项目技能只更新仓库维护源。安装副本由维护者统一从已核版本同步并记录摘要；不在安装目录并行发展另一份唯一实现。

## 启动时效失败与真实接续的记录

最新公开入口在仓库内 `docs/reviews/2026-10-26-PTN启动时效修复与八卡接续巡检.md`。jvhrd的真实失败发生在CUDA前：旧control观测过期，1800秒内未取得新材料，所以未创建run。保留该任务失败与原control，不能把它改写为NaN复发或覆盖为后继成功。ctjsk的八rank恢复及首次真实SGD已经实读，完整第48轮与新检查点仍分别待验。

`refresh_terminal_refs.py`是仓库维护工具，不追加进旧冻结候选包。默认dryrun不改规范control；执行前先封存原字节，再按原子单文件发布更新真实新观测，记录输入SHA、before、after与部分完成。原件中的平台状态来自实际观测，文件检查不是平台认证；工具不检查平台当前writer，不因run不存在便授予启动许可。外部无并发writer前提、固定候选包CPU恢复、唯一后继与实际首更新都须分别有证据。

文档同步或已存在的监控提示不能重新启用已暂停的heartbeat，也不等同于新持久调度授权。技能内部references保留相对链接；仓库路径用明确代码字面，安装后不能通过跨出技能目录的Markdown相对路径寻找仓库。安装副本仍由维护者从最终已核版本同步。
