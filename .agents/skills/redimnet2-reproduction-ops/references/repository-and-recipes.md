## 当前三语料 B6 设计

当前选的是 VoxCeleb2、VoxBlink2、CN-Celeb2 三语料，B6 ReDimNet2Wrap，16kHz 波形输入、192维 embedding。PTN 跑 120轮；LM 1轮在 PTN 120轮完成后，从**该次运行第115轮**初始化，不是第120轮，也不是最后若干轮的平均。公开配置文件名100ep、实际轮数120和LM初始化115之间不一致，所以推不出论文作者真实的最终训练轮数。

| 项目 | PTN | LM |
|---|---:|---:|
| 样本数 | 11,521,178 | 5,021,010 |
| 原始说话人/类别 | 119,274 / 357,822 | 115,362 |
| 每卡/8卡总batch | 96 / 768 | 48 / 384 |
| 帧数/采样点 | 200 / 32,240 | 500 / 80,240 |
| 每轮批数 | 15,001 | 13,075 |
| speed | 三语速扩类 | 关闭 |
| margin | 第15轮开始，第30轮达0.2 | 0.3 |

PTN 的样本组成：Vox2 1,092,009、VB2 9,904,382、CNC2 524,787。LM 去掉了3,912名不符合条件的说话人，没有新增说话人；分类头按名字映射，随机切片替代不了这个映射，切片出来的行号与说话人对不上。

SGD 的基准 LR0.06，按 legacy 缩放 `8*96/64=12` 后峰值0.72，8轮warmup；momentum0.9、Nesterov，骨干 WD2e-5、投影头1e-5，AMP 打开，seed42。当前 `compile_backbone:null`，`legacy_aug:true` 走原始增强目录；训练实际的 loss 来自 SphereFace2 投影头的返回值，残留的 CrossEntropyLoss 只是字段名，不能照它给这一步命名。

当前官方复现配方里没有变长/VAD裁片；这两项属于个人改进/独立消融，而且同时改了多个设置，不能算单因素对比。首次32批NaN短测已经确认调度器的 epoch 长度错位在15001/32；但没有首次异常算子的证据，不能断言这是唯一根因。第二版 PTN64步、LM32步的调度对齐只证明操作路径通了，不证明最终精度。

## 评测与导出语义

轮末的快速验证：Vox1-O 37,611对、4,708条音频，固定取前8秒，短音频wrap，embedding 归一化后算 cosine。最终质量要在同一套整段语音协议下比较 Vox O/E/H/B、VOICES、CN，eager FP32，CN 用embedding平均。旧的拼接说法已经过时。

公开三语料权重在整段上的 O/E/H EER 是 0.255%/0.409%/0.790%，这组数是公开参考结果，不能写成本次自训已经达到。导出加载需要训练配置、严格backbone，并规范化 `module`/`_orig_mod` 前缀；重复键拒绝，只丢弃已经识别的投影头。当前修复已有真实PTN/LM四条加载路径192维且maxdiff0的证据；旧说法“检查点格式必不兼容”是已经解决的历史问题。最终自训导出和六路双权重评测的完成状态仍要重新验证。
