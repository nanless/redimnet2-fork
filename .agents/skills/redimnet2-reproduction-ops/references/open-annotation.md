# 开源模型自动标注

维护代码在 `tools/open_annotation/`。本轮批量范围是 VoxCeleb2、VoxBlink2、CN-Celeb2 的实际训练来源，主训练与大间隔清单中的同一来源只计一次。额外评测域、噪声、房间脉冲和业务诊断不加入主分母。范围改变须按本次用户要求重新确定，不能沿用历史混合批。

保留原件编码摘要、原采样率多通道解码摘要、模型实际输入摘要、时钟和原始说话人/用途信息。旧 VAD 只能据实际存在的身份材料复用，不把路径/stat 绑定描述成旧音频 SHA 绑定；无关路径不能用相同文件名放宽。

必须保存模型原始文字和语言、归一化每一步、原生时间、库内修补和几何错误。零长、越界、生成截断、空转写、不支持语言、数字/混合脚本读法未决均入完整分母。对多个汉字组成的原生粗词不平均拆时间，机器听辨不充作人工审核。

单窗执行合同须绑定实际调用宽度与缓存语义；同窗在不同批次中可能变化，不能仅往缓存键加批大小而继续跨组合复用。恢复比较完整基线与新输出的原生 ASR、对齐及观察层；分开旧结果复用、缓存消费与实际重执行。

发布需核原子输出、提交记录、队列归属、代次与输入集合，不只看 worker 退出码。CPU 队列测试不能证明远端文件系统或跨节点锁语义；现场验收分别保存资源主动证明、实际 worker、所有 rank 和归还快照。

候选状态和几何合法不能把 `usable_for_training/evaluation` 改真。保护引用作为显式外部输入按调用者提供并核实的固定 SHA 绑定；公开测试用合成保护表，不发布真实名单。未知或失败仍允许诚实保存为待核自动标注，但不能承诺完整字准确率。
