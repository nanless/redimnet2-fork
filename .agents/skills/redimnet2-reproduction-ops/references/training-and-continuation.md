# 主训练和大间隔微调

训练入口在 `applications/speaker_rec/`，跨段准备工具在 `tools/lm_continuation/`。先读相应目录说明，再执行仓库测试；不能从旧实验目录导入仓库中没有的唯一依赖。

历史普通接续入口、数据子进程和恢复检查参考在 `tools/ptn_reference/`。先读其 README、逐文件索引和公开维护差异；只可用 `audit_reference.py` 核摘要、Python 编译语法与 `bash -n`。不要导入归档模块或执行 `archive/launch.sh`，其中含实际启动和进程管理动作。缺少原合同、源码凭证、终态和权重时不能补空文件放行；`runtime_admission` 始终为 false。去除真实诊断标识后的公开版本有新身份，不能声称与全部历史文件原字节一致或已继承 GPU 证明。

同阶段恢复应恢复检查点中的模型、优化器、梯度缩放器及训练步数，核分类头说话人映射。主训练转大间隔阶段则遵配方选择初始化轮数、重建阶段优化器；不要把两者混为“继续训练”。完整验证最优权重与配方指定的阶段初始化权重也要分清。

维护版训练入口自动接续按`model_N.pt`的数字轮数选择，不能按复制后的修改时间选择；显式`checkpoint`仍优先。核文件名轮数与保存的`epoch`一致，再确定绝对训练时钟。同阶段还须核完整模型键、形状和原`spk2id.json`，允许显式提供原映射路径；不能先覆盖旧映射再声称身份一致。分类头形状变化的阶段初始化应同时重置优化器、缩放器和阶段轮数，而不是只重置优化器却从主训练末轮继续计时。上述是新维护实现的规则，不是对旧冻结任务的热修改许可。

跨两段记录时绑定前段终点、后段八进程的同一恢复来源、完整训练与验证记录、固定依赖、异常审查和新鲜终态。原段允许的逐条已审异常不能自动移植到后段。裸 `LibsndfileError`、`OSError` 或其他异常即使没有 Traceback，也不能漏过后段检查。

CPU 准备检查应始终与真正执行分开：合成的未来完成记录只验证代码分支，不能授权启动。真实读取检查点前限制到可信路径，拒绝通过自供摘要加载任意 pickle。输出只写本次专用准备目录，不创建训练输出树，不拿启动锁冒充实际许可。

巡检记录需包含日志观测时刻、实际步数、验证指标、最新与最佳检查点、八个计算进程和 GPU UUID。0% 利用率不是空闲；没有计算进程、显存和真实设备身份的完整证据，不据此启动新 GPU 工作。预计剩余时间说明窗口吞吐、剩余轮数及维护/排队不确定性。

## 前向非有限值与隔离诊断

2026-10-25的接续任务在48轮1773批rank4发生真实故障：增强后FP32输入有限，FP16向量先出现NaN，FP32损失随后NaN。没有故障时权重/RNG，不能把model47加原波形重放正常当作故障已修复；也不能把此前1772个训练迭代一律说成1772次实际SGD更新。GradScaler可能跳过更新，而本批失败发生在其反向缩放之前，降低scale不能直接解决本批前向问题。读取最新带日期审查报告再判断状态，不延用“八卡正常”旧结论。

CPU入口是`tools/ptn_diagnostics/inspect_numeric_cpu.py`，只读取SHA固定的可信张量/检查点，CUDA隐藏、限线程与读带宽，分开统计模型和动量。所有输出使用新文件并在现场目录外；错摘要或不安全输出在反序列化前拒绝。保留原JSON、原wave、完整rank日志与原SHA，不把截图手抄的形状或缺字符摘要当最终身份。

`tools/ptn_forward_probe.py`仅用于指定空闲双卡的单批故障诊断。必须从全新进程、`python -B`、UUID绑定、共享协作锁、5秒双快照、冻结源与输入摘要开始；每个case独立进程并重新取空闲证明。驱动host PID若在容器内无法证明归属，不能放宽成“当作自己的PID”。普通模块核文件来源与SHA，namespace包核唯一冻结目录；每个case都做导入核验。保持原模型/配置/完整批，不能再做数据增强。train前向会更新BN，所有对照重新加载状态。

模块探针会改变同步和运行开销，只能定位模块边界；CPU直接half的溢出不等于CUDA autocast的实际dtype策略。`--no-grad`的FP32对照必须明确没有梯度图，不能写成训练验收。该工具不做反向、优化器或调度器，不授予生产接续资格。当前同一完整批的model47 AMP和FP32诊断均有限，现场首坏算子仍未确认。

安全恢复应保留失败段，先完成数值问题的可复验修复/更完整故障状态取证，再建立新版本和47→48的严格恢复合同；原优化器、scaler、说话人映射及绝对时钟均核。旧35→36入口不能直接套用。后续记录是1—35、36—47、48—120三段，旧两段LM准备器应保持拒绝，不能改冻结记录伪造已完成轮次。
