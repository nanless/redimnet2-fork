# 完整字词的单位、训练与评测

`schema.py`是完整字消费的稳定入口。每条记录绑定原音SHA、原始采样率和采样点区间、说话人、完整字词、文本来源与边界审阅状态。中文按汉字、英文按词计数；数字、混合文字和未知语言不能擅自猜读法。读取保持连续原声，不拼VAD段、不补齐、不循环、不作任意秒数裁剪。

强制对齐自动结果是待审候选。默认`load_dataset`拒绝候选；显式工程候选开关不将其变为人工真值。正式训练仍需明确训练split与足量合法、不同来源，不能把诊断样本或评测音频改名后混进训练。

- `prepare.py`选择说话人隔离数据和1/2/3/6单位交叉试验。
- `align.py`保原生对齐及候选身份，必须显式选择模型；普通CPU测试用合成返回，不调用真实模型API。
- `train.py`用于CPU工程检查，逐条真实长度前向、按固定条数累积，再完成一个完整优化步。`gpu_train.py`及双卡启动器保留早期两卡受控入口；新的双卡/八卡实验优先用[受控双卡与八卡入口](../word_ft_v3/README.md)。
- `evaluate.py`和`scripts/eval_word_matrix.py`分别报告注册端×测试端单位数、相似度与等错误率/最小检测代价；阈值只在隔离开发集校准，测试集不重新拟合。候选只能输出明确标记的研究结果。

同阶段恢复必须恢复完整模型/头/优化器/scaler/随机状态与样本位置；从官方骨干开始的新微调不恢复不存在的官方分类头或历史动量。新维护版已修旧v1跨轮全局批重复；来源身份变化使旧保存点不能静默进入新实现。

```bash
CUDA_VISIBLE_DEVICES='' PYTHONPATH=. python -B -m unittest discover -s tests -p 'test_word_*.py'
```

其中真实双rank CPU测试只在127.0.0.1临时端口使用Gloo，前向模型和音频都在临时目录合成，不需要GPU、外网或B6下载。实际训练仍需要明确受控输入、官方模型、私有Linux解码库和独立输出目录；不把CPU合成结果写成真实微调效果。
