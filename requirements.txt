# Dependency list for this repository.
#
# Two groups are marked below. Installing everything in this file gives you a
# working training environment; if you only want to run inference, the smaller
# group is enough.

# --- Inference only: the `redimnet2` package and `hubconf.py` ---
# `redimnet2` imports torch, torchaudio, numpy and scipy at import time, and
# `hubconf.py` pulls in the package. Nothing else is needed to load a published
# checkpoint and compute speaker embeddings.
torch
torchaudio
numpy
scipy

# --- Training only: applications/speaker_rec ---
# Everything below is imported by the `wespeaker_lite` training stack or by the
# data-preparation scripts under `applications/speaker_rec/examples/`.
pandas          # train.py writes val_log.csv; data-prep scripts join duration tables
pyyaml          # reads the recipe .yaml configs
soundfile       # libsndfile bindings for reading wav/flac
resampy         # resampling in dataset/processor.py
lmdb            # only for reading pre-built LMDB packs (legacy path)
fire            # command-line entry point of bin/train.py
tableprint      # per-step logging table in bin/train.py / utils/executor.py
tqdm            # progress bars
scikit-learn    # EER and ROC computation in utils/executor.py
pyarrow         # parquet output for duration tables (vb2_vox2_cnc2 scripts)

# --- 语音活动标注工具专用：applications/speaker_rec/scripts/vad ---
# FireRedVAD（外部仓库，没有复制进本仓库）需要下面这两个包。
# 它们**不在**本仓库训练用的 conda 环境里，所以那套工具默认跑在另一个
# 解释器里（见 docs/09-VAD标注与RTTM.md 第 4.1 节）。
kaldiio
kaldi_native_fbank
