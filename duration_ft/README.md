# 按时长取段的工程对照

本目录是整数秒取段的工程对照，不保证切在完整字词边界。正式的完整字自然变长实验请读[完整字模块说明](../word_ft/README.md)和[双卡与八卡说明](../word_ft_v3/README.md)。不能把半秒或固定秒数裁片当作完整字测试。

`data.py`核原音、FireRed边界和来源摘要，按共同五秒语音轴选择嵌套时长；这里会拼接VAD语音段，完整字分支则保持原声连续区间，两者不混用。`train.py`从已核官方骨干建立新分类头与冷SGD，冻结批归一化运行统计、保留仿射梯度。完整优化步保存模型、头、优化器、scaler、全部rank随机状态、全局样本位置和来源身份；恢复必须同输出、同配置、同数据与同源码。`resume_guard.py`在写锁前和锁内核已有日志及保存点，拒绝不完整或向后回退。

新维护版修正旧无限流在轮次交界处同全局批重复的问题：排列在样本池大小与全局批量大小的最小公倍数处重洗；每个全局步源不重复，每个完整样本池周期都覆盖所有源，不丢尾。配置和源码身份记录变化，不能静默恢复旧代码保存点。`config_checks.py`在设备初始化前拒绝布尔计数、非法seed、非有限优化器和分类头数值；官方模型摘要固定。

`evaluate.py`逐条真实长度提向量，保共同试验集合和来源身份，解码错误有上限、模型/设备错误停止；不完整结果不输出有偏的主指标。`metrics.py`计算等错误率和最小检测代价，区分测试集上的区分阈值与开发集冻结阈值。`plots.py`只画已完成结果；`scripts/summarize_duration_results.py`支持无图统计。

本机CPU合成回归需要现成numpy、SoundFile、SciPy、PyTorch和Matplotlib。代码不自动安装依赖或下载权重；缺依赖明确跳过相应测试，不当作模型验证通过。

```bash
CUDA_VISIBLE_DEVICES='' PYTHONPATH=. python -B -m unittest discover -s tests -p 'test_duration_*.py'
```

模型、数据清单、原音、完整日志和运行输出不入库。真实B6、GPU吞吐和质量收益仍需独立现场验收；CPU小模型测试不能替代。
