# 原生补零特征的纯合成诊断

结论和公开合成图见[根因报告](../../docs/reviews/2026-10-28-原生合批补零与声学特征差异根因.md)。维护工具不读取真实音频或模型权重，不构造ASR模型，不调用API或GPU。

`diagnose_native_feature_padding.py`的固定计划包含schema、实际冻结pilot合同pin、官方Whisper源pin、官方processor源pin、该ASR目录特征配置pin，以及全新输出目录。schema为`annotation-native-feature-padding-diagnostic/v1`。默认`--plan ... --plan-sha ...`只检查；显式`--execute`才使用16000/16128/49408/401408点合成目标及416000点同伴，进行B1/B4/B8 CPU特征对照。长度函数仅提取已pin官方纯算术AST，不导入Qwen模型类。

输出固定有效特征、mask、官方音频占位长度、raw-log最大值及位置、前/中/尾最大差。额外等长合批和高幅同伴用于区分FFT、跨batch归约与本条动态范围传播。原始合成有效数组另存NPZ，`allow_pickle=False`读取；不把数组加入Git。首次真实诊断及已授权的第二次细分诊断均完成，后续解释和画图复用数组，不再次测量。

绘图入口只读数组，不提特征，命令形如：

```sh
python -B tools/open_annotation/plot_synthetic_feature_padding.py \
  --arrays /私有合成有效数组.npz --arrays-sha 实际数组SHA \
  --result /同一次合成诊断.json --result-sha 实际结果SHA \
  --output /全新公开合成图.png --font /实际存在的中文字体.ttc
```

工具会核实际16000点样本形状128×100、raw只frame99变化、归一化后99帧变化、报告和数组SHA一致。图不标真实原件路径或source ID。输出数字的单位和原始/归一化尺度不同，不能把两条线的高度当同一物理单位；两幅尾部热力图分别注明尺度。

操作计划、配置读取、源码、实际输出及异常保留在本仓库`.audit-local/asr-speed-20261028/native-feature-padding/`；维护代码和公开合成图正常提交，原9.28MB私有数组和真实原件不提交。rootcause验证不等于文字/完整字边界验收，更不授予正式标注或训练资格。
