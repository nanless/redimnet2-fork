# 已保存原音与字界图审

`plot_saved_boundary_review.py`只读明确选出的1—32份本机原音和原始侧车，不运行ASR、对齐模型、API或GPU，不改动原标签、未知原因或使用资格。它用于把机器给出的不同时间放到同一张声学图中，帮助复核已有样本；图审不能代替听音，更不是人工完整字金标。

## 输入及身份

输入JSON为数组，每项含`review_id`、`sample_id`、`local_sidecar`和`row`。`row`中必须有`source_id`、`audio_path`、`sidecar_sha256`和`audio_recorded_file_sha256`。`audio_path`只用来取得原扩展名，不访问其远端位置。本机音频由`--audio-root/review_id/source.wav`或`source.flac`提供；不接受软链接。真实样本ID、音频、选择清单和侧车只保存在私有证据目录，不提交公开仓库。

执行前核对选择文件SHA、侧车SHA、编码原音SHA、源ID、解码后的实际采样率/帧数/声道数，以及原采样率多声道小端float32交错PCM SHA。全部样本核对成功后才建立全新的输出目录，已有输出绝不覆盖。若源码在绘图期间改变，不能发布完成收据，已生成图片留作未完成尝试。

## 图和文字怎么读

每源保存整段图、每个模型窗图，以及首尾、窗口接缝和有限异常附近的放大图。波形按原采样率显示，长片段使用每个分箱的最小和最大幅度，避免直接抽点漏掉短脉冲。频谱使用约25毫秒窗和约5毫秒步长。它不能从视觉上分辨或确认1采样点差的声学真值。

时间轨分开显示旧VAD、作者原生时间、作者FIX后的时间和最终源采样点单位。原生/FIX毫秒均加上该模型窗在原源内的context起点；最终units使用其自身源采样点，不混用两个时钟。红色x保留零长或倒置项，不将其补成正长度。源尾外留极小图宽显示旧VAD超尾，但不补音频。虚线表示模型窗口负责的原源范围边界。

HTML逐窗保存ASR原文、标准化文和逐项表。表中并列字词、原生毫秒、FIX毫秒和源采样点，底色提示作者FIX改变或零长/倒置；未进入该窗负责范围的词项明确显示未进入owned units，不能当成删除了原始输出。所有原始窗口和完整时间也保留在每源`observations.json`。

## 执行与结果边界

用仓库中具有numpy、soundfile、scipy和matplotlib的CPU环境运行：

```bash
python -B tools/open_annotation/plot_saved_boundary_review.py \
  --selection /absolute/private/selected.json \
  --selection-sha 选择文件的64位SHA256 \
  --audio-root /absolute/private/audio-selected \
  --output /absolute/private/new-boundary-figures
```

结果首页为`index.html`，各源独立目录包含图片、逐项HTML和JSON。`receipt.json`绑定选择文件、执行源码、解码证明和每份结果的SHA。收据明确`human_gold=false`、`label_eligibility_released=false`和`model_GPU_API_execution=false`。失败时保留已经产生的图和日志，但不能把缺少完成收据的目录称作完整验收。

测试入口为`python -B -m unittest tools.open_annotation.tests.test_plot_saved_boundary_review -v`。合成测试覆盖context源钟偏移、原生零长与FIX差异保留、VAD超尾保留、实际绘图及结果SHA、编码或PCM摘要不符拒绝、重复/非有限JSON及软链接输入拒绝。它只证明工具行为，不能证明真实文字或边界准确。
