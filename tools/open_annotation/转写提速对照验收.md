# 转写提速对照怎样核验

`audit_speed_comparison.py`只读取已经结束的有限试验，比较同一批来源的完整输出。它不执行模型、不读取原音、不领取分片、不改生产队列。报告只能写到既有证据目录中的新文件，不能写进任何被比较任务的输出、队列或资源目录。

## 准备两个试验描述文件

每个文件使用`redimnet2-annotation-speed-track/v1`，字段如下。路径都使用实际绝对路径，摘要为64位小写SHA256。

```json
{
  "schema": "redimnet2-annotation-speed-track/v1",
  "contract": {"path": "/absolute/code/contracts/pilot.json", "sha256": "填写实际摘要"},
  "index": {"path": "/absolute/inputs/index.json", "sha256": "填写实际摘要"},
  "queue_root": "/absolute/run/queue",
  "output_root": "/absolute/run/labels",
  "resources_root": "/absolute/run/resources-attempt1"
}
```

两个试验必须已有完整终态：队列中没有活动租约，全部计划来源都有侧车、逐源提交标记、分片提交和完成槽；资源目录有父摘要、各worker摘要、终态ready/ACK及真实资源挑战和归还双快照。工具重新读取这些文件，核其摘要、身份、计数及来源集合。最多20000条来源，防止把有限速度比较误用于运行中千万条全库。原音和模型文件不在本工具内重新读取；本工具核的是已保存输出的身份链，不是原声的现场重哈希。

```bash
python3 -B tools/open_annotation/audit_speed_comparison.py \
  --baseline-spec /absolute/baseline-track.json --baseline-spec-sha '<实际SHA256>' \
  --candidate-spec /absolute/candidate-track.json --candidate-spec-sha '<实际SHA256>' \
  --mode speed --output /absolute/audit/new-comparison.json
```

`speed`要求来源集合完全相同、模型/第三方源码/解码器和除显式转写计算配置外的runtime相同。新旧配置不同会使用各自真实合同，不能把新配置写进旧证据。原始文字、规范文字、语言、生成token、结束标记及原生/FIX时间分别比较；目标文字与词项序列不同的窗口不强行配边界。没有可比较端点时报告为空值，不记为零误差。来源失败、空转写和缺窗都留在完整分母中。

报告把已有完整侧车复用、阶段缓存命中和实际模型调用分开。只有两轨都全新推理、都实际执行ASR、原音/窗口身份一致且配置与真实执行观测对应时，才提供全冷流程的速度比。复用输出的试验仍可比较文字和边界、查看实际新推理计数，但不能靠缓存称为模型提速。

legacy基准不强加新的attention配置。新引擎保存真实参数dtype、子模块配置以及首个成功ASR调用的逐attention模块forward/F.sdpa观测。工具按实际模块配置核调用次数，允许诚实记录legacy中的非一致子模块策略。候选显式配置须实际兑现，SDPA还核Q/K/V张量dtype。这是Python调用和张量入口观察，不是CUDA内核分析。旧摘要缺少这些观测时不补造执行证明，也不提供对应全冷速度结论。

## 恢复比较

将右侧描述文件改为恢复后的完整结果，使用`--mode recovery`。恢复轨可为基线输入的明确子集；合同必须逐字段相同，子集中的来源记录也必须完全一致。工具严格比较同配置的原生窗口、观察与质量字段，只排除窗口顶层的两项缓存命中标记；实际新推理和旧结果复用在运行计账中分别保留。不相等时仍保存完整比较报告，退出码为2。比较完成的0退出码不代表人工质量、模型收益或八卡提交已批准。

## 质量结论和私有结果

报告含逐来源标识、原始模型文字、时间与差异，必须保留在私有审阅目录，不能提交到公开Git。输出始终保留`formal_admission=false`、人工文字/字界准确率未证明、训练与评测资格未释放。机器结果一致只是没有观察到该种变化；相差若干毫秒也不是相对于人工真值的误差。

本机已有困难例的图、内部模型听辨和逐条候选可用于找争议。历史18例与34例材料不能自动成为人工完整字金标。是否具备人工审核、是否可以提交新的机器标注任务，仍由独立质量与运行审阅决定，本工具不自动选择候选或启动八卡。
